## Highlights

- **New interface.** Compact proxy and rule lists with one-click actions, centered modal editors
  with tabs, Lucide icons, toasts and accessible in-page dialogs instead of browser prompts.
- **English and Russian UI**, chosen by the browser language; country names and decimal
  separators follow it too.
- **Themes.** System, Light and Dark with six accent colors, all checked for WCAG AA contrast.
- **In-app Help** with searchable articles and **?** tips next to fields that raise questions,
  including a regular expression cheat sheet and flag explanations.

## Proxies

- Import proxies from pasted text or `.txt`/`.csv` (URI, `host:port`, `user:pass@host:port`,
  `host:port:user:pass`, CSV/TSV, IPv6) with a preview, or fill the editor from one pasted string.
- Copy a profile as URL, curl command or `host:port:user:pass`; export the list as text. Native
  JSON export now includes credentials by default (opt-out available).
- Search, filters and bulk check/delete.
- Checks show the full result: status, response time, external IP and country with a bundled flag.
- **Test speed** downloads a bounded test file (15 s / 5 MB) through the proxy and shows Mbit/s.
  The download URL is shown before you confirm and can be changed in General.

## Rules and overrides

- Rules list with route chips, enable switch, filters, bulk enable/disable/delete and a readable
  pattern tester with a verdict next to each URL.
- Temporarily disable a rule for the session.
- Temporary overrides section and popup list: change scope or route, make permanent, remove.

## Fixes

- Chromium manual check could read `about:blank` instead of the response.
- Row menus are no longer clipped at the bottom of lists.
- A literal `$` in help texts was dropped by the browser.
- Interrupted migrations now restore a backup written by an older schema.
- Dependency security updates (no high or critical advisories remain).

## Data

Configuration schema moves from v3 to v5 (accent color, speed test URL and result). Existing
settings and older backups are migrated automatically.

## Privacy

No telemetry. Proxy check and speed test run only after an explicit click; the check endpoint and
the speed download server see the proxy's exit IP. See [Privacy](../privacy.md).
